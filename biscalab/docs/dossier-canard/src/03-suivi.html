Où en est le canard

Tout ce qui est enregistré ici vient du dépôt du club : séances, pièces, achats, tests, mesures, décisions. Chacun peut enregistrer depuis cette page ; tout le monde voit la même chose.

Ce qui ne se négocie pas

La politique de marche fournie suppose exactement ceci. Tout écart impose un réentraînement.

  • Servos STS3215 7,4 V, rapport 1/345 (réf. C001, « 19 kg·cm ») — pas la 12 V, pas les rapports 1/191 ni 1/147.
  • Batterie 2S (2 × 18650 haute décharge ≥ 25 A) — jamais 3S.
  • Semelles en TPU à 40 % : c'est le seul contact modélisé avec le sol.
  • Géométrie identique aux STL amont, masses à ±10 % près.
  • Gain P = 30, boucle 50 Hz, action_scale 0,25.
Comprendre pourquoi

Les 5 règles d'or

  1. Si ce n'est pas sur GitHub (issue ou journal), ça n'existe pas. Signal sert à discuter, GitHub à décider.
  2. Pull en arrivant, Push en partant. Un fichier CAO n'a qu'un éditeur à la fois : celui qui s'est assigné l'issue.
  3. On ne modifie jamais un fichier amont : on le copie dans biscalab/, puis on le modifie.
  4. Pas de phase suivante, ni d'achat suivant, sans fiche de test validée.
  5. Sécurité non négociable : batterie jamais en charge sans surveillance, laser jamais seul, matériaux interdits affichés.

Comment ça marche

Le travail se fait dans Travaux par phase (une tâche, un bouton) et dans les registres (pièces, achats, tests, mesures, décisions), qui listent ce que le plan attend. Chaque formulaire, directement dans la page, prépare un petit fichier texte et ouvre l'éditeur de GitHub déjà rempli ; il ne reste qu'à cliquer Commit changes. Le fichier arrive dans biscalab/ du dépôt du club et cette page le lit à la prochaine actualisation. Il faut un compte GitHub membre du dépôt (cours 1). Les cases « cours terminé » du parcours, elles, restent personnelles à chaque appareil.

Journal des séances

Une entrée par séance de travail, cinq rubriques : présents, fait, mesures, problèmes, décisions. Ce qui n'y est pas n'a pas existé. Les tâches cochées dans une séance comptent dans le planning.

Travail

Les sept phases et leurs tâches

C'est ici qu'on travaille. Chaque tâche dit où elle en est, d'où vient son avancement, et porte le bouton qui l'enregistre : la commande de la phase, la pièce imprimée, la mesure, la fiche de test déjà rédigée… Les phases avancent en parallèle ; seule la phase 2 porte un GO / NO-GO, avant l'achat des 12 servos restants.
