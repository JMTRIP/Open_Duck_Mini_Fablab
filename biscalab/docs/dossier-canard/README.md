# Dossier Canard BiscaLab (v1.2)

Dossier de travail du projet Open Duck Mini V2 au BiscaLab : cours, glossaire, pages opérationnelles.

Pour le lire : ouvrir index.html dans un navigateur. Les polices demandent une connexion internet.

Le mode « application installable » (PWA) ne fonctionne que si le dossier est hébergé en HTTPS (par exemple GitHub Pages).
