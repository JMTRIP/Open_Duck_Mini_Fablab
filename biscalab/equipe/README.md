# Rôles de l'équipe

Un enregistrement par attribution des rôles, créé depuis la page Équipe et méthode (bouton « Attribuer les rôles »). Le fichier le plus récent remplace entièrement le précédent ; les anciens restent ici, c'est l'historique. Ce README n'est pas lu par la page.

## Modèle

```
---
type: equipe
date: 2026-10-22
par: Jean-Marie
---
Maître d'œuvre: Jean-Marie
Référent outillage numérique: Laurent
Administrateur du dépôt: Jean-Marie
Trésorier-acheteur: 
Référent impression 3D: 
Référent laser: 
Référent électronique et code: Laurent
Référent sécurité: 
```

Une ligne par rôle, `Rôle: Prénom` ; vide = à attribuer. On peut ajouter des rôles.
